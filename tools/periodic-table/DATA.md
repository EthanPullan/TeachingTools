# Periodic Table — where the data comes from

None of the element data in `index.html` is typed by hand. The block between `DATA-BEGIN` and
`DATA-END` is generated by `build-data.py` from three published sources (retrieved 2026-11-05):

| What | Source | URL |
|---|---|---|
| Symbol, name, element type (category) | PubChem Periodic Table (NIH / NCBI) | https://pubchem.ncbi.nlm.nih.gov/rest/pug/periodictable/JSON |
| Atomic mass | Periodic-Table-JSON (Bowserinator, GitHub), cross-checked against PubChem | https://raw.githubusercontent.com/Bowserinator/Periodic-Table-JSON/master/PeriodicTableJSON.json |
| Common oxidation states (→ common ions) | Wikipedia, *Oxidation state* → "List of oxidation states of the elements", which is based on Greenwood & Earnshaw, *Chemistry of the Elements*; the most common states are printed in bold | https://en.wikipedia.org/api/rest_v1/page/html/Oxidation_state |

Regenerate: download the three files, then
`python3 -I build-data.py pubchem.json bowser.json oxstate.html index.html`

## Rules and caveats

**Atomic mass.** Shown to 3 decimals, rounded mechanically from the dataset. Elements with no stable
isotope have a whole-number mass in the dataset and are shown in brackets, e.g. `[98]` (IUPAC
convention: mass number of the longest-lived isotope). The script stops if the two sources disagree by
0.25 or more. PubChem rounds a few masses coarsely (Li 7.0, Pb 207), so the Bowserinator value is used.
Some values are older IUPAC figures (e.g. Ge 72.631, Pb 207.21).

**Names and types.** PubChem, verbatim (US spellings: aluminum, cesium, sulfur). Polonium is a
"metalloid" in PubChem.

**Common ions.** An oxidation state is not always the charge of a real monatomic ion (Cl +7, Mn +7…),
so the bold ("most common") states are filtered by a stated rule, in `build-data.py`:

- cations (+) for hydrogen and every metal category; anions (−) for nonmetals and halogens;
- only simple charges, |charge| ≤ 4;
- elements where the source bolds nine or more states (carbon) show none;
- metalloids and noble gases show none.

Consequences worth knowing: the source marks only +2 as most common for copper and only +3 for gold,
so Cu⁺ and Au⁺ are not shown; vanadium, niobium, tantalum, uranium and others show none because their
common states exceed +4. If you want a different convention, change the rule (or the list) in
`build-data.py` and regenerate.

## Saved files

"Save data" writes a JSON file; "Save PDF" embeds the same JSON in the PDF as a file attachment
(`periodic-table-data.txt`, base64 between `TTPT1:` and `:TTPT1END`, uncompressed). "Open…" reads either.

```
{ "type": "teachingtools-periodic-table", "version": 1, "savedAt": 1762300000000, "active": "7A",
  "tables":  { "7A": { "H": "Ada Lovelace", "He": "Alan Turing" } },   // one table per class
  "classes": [ { "name": "7A", "students": ["Ada Lovelace", "..."] } ],
  "show":    { "num": true, "mass": false, "ions": false } }
```

A PDF that is re-saved, optimised or printed by another program may lose the attachment; "Open…" says so
and "Save data" is the safe copy. PDF text uses Helvetica (Western European characters); other scripts
print as `?` in the PDF only — the embedded data keeps the real names.
