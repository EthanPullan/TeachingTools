Graph Maker graphs for tests

Graph type

Grid layout

Coordinate grids keep square cells, so a 10 × 10 grid stays 10 × 10 squares.

Printed size

Sizes are real print sizes. Full and half width fit a letter or A4 test with normal margins.

The legend appears when there are two or more series.

Bar graphs: the first column holds the category names; each series is a set of bars.

You can also paste straight into a cell: a block copied from Excel or Google Sheets fills in from that cell. Enter moves down. Red cells aren’t numbers and are left off the graph.

Paste from a spreadsheet

Copy cells in Excel or Google Sheets and paste them here. This replaces the table. A header row like Time (min) fills in the axis label and unit. For coordinate grids and scatter plots, a first column of names (A, B, C…) becomes point labels.
