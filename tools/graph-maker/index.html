Graph Maker graphs for tests

Graph type

Grid layout

Coordinate grids keep square cells, so a 10 × 10 grid stays 10 × 10 squares.

Printed size

Sizes are real print sizes. Full and half width fit a letter or A4 test with normal margins.

Slice labels

Slices run clockwise from twelve o’clock, in table order. The category names are “X-axis numbers” and the percent / degree labels are “Point labels” on the Test tab.

Whiskers

The box runs from the lower quartile to the upper quartile with the median marked. Quartiles are the medians of the lower and upper halves (the middle value is left out when there is an odd number of values).

Bins

One column of values goes in the table. A value on a bin’s upper edge counts in the next bin (a bin is “from … up to but not including …”).

Physical scale

A grid square is one major step. The page grows to fit the grid, so the size above is ignored. Paste the PNG into Word at 100% (it is stamped 300 DPI) and a ruler will measure true.

Error bars

Bars run from each value minus the error to plus the error. Turn them off in the question with “Error bars” on the Test tab.

The legend appears when there are two or more series.

A number line has no data table: add its points, rays and intervals as marks on the Draw tab.

Bar graphs: the first column holds the category names; each series is a set of bars.

Pie graphs: category names in the first column, amounts in the second. Slices are drawn in table order.

Box plots: each column is one box (name it in the top row). Type or paste the measurements down the column; columns can be different lengths.

Histograms: paste or type one column of measurements; the tool groups them into bins.

You can also paste straight into a cell: a block copied from Excel or Google Sheets fills in from that cell. Enter moves down. Red cells aren’t numbers and are left off the graph.

Paste from a spreadsheet

Copy cells in Excel or Google Sheets and paste them here. This replaces the table. A header row like Time (min) fills in the axis label and unit. For coordinate grids and scatter plots, a first column of names (A, B, C…) becomes point labels.

Presets & recent graphs

Pick one to start from it (Undo brings back what you had). Your saved presets and recent graphs are kept in this browser only; the Save button (a .json file) is the real backup.

Graphs to print

Graphs print at their real size, and smaller ones sit side by side on the page. In the print window choose “Actual size” / 100% and turn off headers and footers.

Keyboard shortcuts

Ctrl ZUndo
Ctrl Shift Z or Ctrl YRedo
Ctrl SSave the graph as a .json file
Ctrl DDuplicate the graph
Ctrl Shift EExport question + answer key
Ctrl PPrint the graph you are editing
K / QShow the answer key / the question
EClick-to-add / drag-to-move tool on or off
HClick-to-hide tool on or off
EscTurn the tools off
?This list

Ctrl is Cmd on a Mac. Letter keys and undo/redo are ignored while you are typing in a box, so they never get in the way of your text.
