Question types

Elements 1 to 36, hydrogen to krypton, unless Heavier elements is ticked. Bohr–Rutherford questions always use elements 1 to 20. Students need a periodic table. Neutron questions name the isotope (chlorine‑35), so there is no rounding to do.

Every question in a set has a different answer, so each one marks its own square.

Send to Bingo

Each question goes with its type as its Bingo category, so in Bingo you can pick a set spread across the types, evenly or by weight. Bingo opens with the questions and decoys ready to use. If that doesn’t work (some browsers block it for tools opened as files), use Download .json, then in Bingo choose Import… and pick the file.
