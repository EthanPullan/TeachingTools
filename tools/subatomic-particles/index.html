⚛ Periodic Table 🎱 Bingo

Question types

Elements 1 to 36, hydrogen to krypton. Students need a periodic table. Neutron questions name the isotope (chlorine‑35), so there is no rounding to do.

Every question in a set has a different answer, so each one marks its own square.

Send to Bingo

Bingo opens with the questions and decoys ready to use. If that doesn’t work (some browsers block it for tools opened as files), use Download .json, then in Bingo choose Import… and pick the file.

Decoys (on the cards, never the answer) 0

Each decoy is a mistake students really make. If a student crosses one off, Bingo’s Check a card tells you which question they got wrong, and how.
